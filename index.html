MTN Website Frontend Recreation

I recreated the MTN website from scratch as a frontend development project, focusing on translating a real-world telecom experience into a responsive, modern web interface. I paid close attention to the original website’s layout, typography, navigation, spacing, responsive behavior, and overall user experience while rebuilding the interface with my own code. The project gave me the opportunity to work on reusable components, responsive design, interactive UI elements, and creating a consistent experience across different screen sizes.

This project demonstrates my ability to take an existing product as a reference, break down its interface into individual components, and turn that design into a functional, responsive website.

Facely

I built Facely as a SaaS-style web app that makes personalized eCards without requiring design skills. I designed and developed the experience from the template gallery to the face-placement editor and final PNG export. I implemented on-device face detection, automatic face positioning, manual scaling/rotation controls, responsive layouts, camera support, and client-side image processing so photos never need to leave the browser.
I also designed the product around a real SaaS experience, including template categories, pricing tiers, Pro features, FAQs, and a complete user flow from discovering a template to creating and downloading a finished card.

This project challenged me to think beyond just building a UI. I had to consider image processing, face positioning, responsive interactions, performance, privacy, usability, and how the product could eventually scale into a real service.

AAJ Express Logistics Website

I designed and developed a modern logistics website for AAJ Express, focused on making shipping services easier to understand and access. I built the experience around key customer actions such as shipment tracking, discovering international and local delivery services, accessing shipping information, and connecting with AAJ’s digital logistics tools.

I focused heavily on responsive design, clear information hierarchy, intuitive navigation, reusable UI components, and creating a professional experience that feels trustworthy for both individual customers and businesses.

The project challenged me to think beyond visual design and build a website around real business goals — helping users quickly understand the service, find what they need, and take action.

Honeyland School Website

I designed and developed the Honeyland School website as a modern digital platform for presenting the school, its academic environment, programs, and key information to prospective parents and students. I focused on creating a clean, responsive experience that makes important information easy to discover while maintaining a professional visual identity across desktop and mobile devices.

This project challenged me to turn a real educational brand into a functional web experience, balancing visual design, usability, responsive layouts, navigation, and performance to create a website that feels trustworthy and easy to use.

PixelPay – Digital Banking Dashboard UI

PixelPay is a modern digital banking dashboard designed to simulate the interface of a real fintech application. The project features a user account overview, transaction history table, balance display with Nigerian currency formatting, and quick financial actions such as airtime purchase, data subscription, electricity payment, and bill settlement. The interface focuses on clean fintech design patterns, responsive layout, and interactive UI elements to create a smooth user experience similar to real Nigerian banking applications.

Tatu Property – Real Estate Investment & Property Showcase Website

Tatu Property is a modern real estate website developed to present large-scale property developments, investment opportunities, and residential projects through a clean and structured digital platform. The website features sections for property listings, project details, image galleries, and company news to keep investors and potential buyers informed about ongoing developments. The interface emphasizes strong visual presentation, intuitive navigation, and responsive design to ensure a smooth browsing experience across devices. This project demonstrates practical skills in front-end development, layout structuring, and building scalable websites for real estate companies and property developers.
